Architecture & Atomic Transaction Flow

Clean Layered Architecture with Drift SQLite & Riverpod.

ACID Compliant

The "Finalize Sale" operation is wrapped in a strict single-transaction block. If power is interrupted or device battery dies, SQLite rolls back completely to prevent orphan records.

Bluetooth Thermal Printing Pipeline

Bitmap raster generation to guarantee 100% accurate Hindi Devanagari text & ₹ symbols.

Devanagari & ₹ Safe

Budget ESC/POS printers cannot reliably decode Unicode UTF-8 Devanagari characters in text mode. The application solves this by rendering the thermal receipt layout into a crisp Flutter RepaintBoundary image buffer, then encoding it as monochrome raster bit-chunks for ESC/POS.

Khata (Customer Credit Ledger)

Computed running balances and instant WhatsApp statement sharing.

Alert Red Highlight

Customer balance is dynamically calculated on the fly from opening_balance + credit_sales - collections. This avoids dangerous balance desynchronization bugs.

// Dynamic running balance query:
SELECT c.opening_balance
  + COALESCE(SUM(CASE WHEN i.payment_mode='credit' THEN i.amount_due ELSE 0 END), 0)
  - COALESCE(SUM(CASE WHEN p.type='collection' THEN p.amount ELSE 0 END), 0) AS current_balance
FROM customers c
LEFT JOIN invoices i ON i.customer_id = c.id AND i.status = 'active'
LEFT JOIN payments p ON p.customer_id = c.id
WHERE c.id = :customerId

Input Validation & Keystroke-Level Robustness

Defensive architecture preventing bad data entry, rapid double-submits, and accidental cart loss.

100% Tested (27 Tests Passing)

1. Keystroke Formatters

Rejects bad characters at the typing level via TextInputFormatters: DecimalInputFormatter(2/3), WholeNumberInputFormatter(99999), DigitsOnlyFormatter, and AlphanumericUppercaseFormatter.

2. Double-Submit Prevention

DebouncedButton locks buttons instantly on tap, renders an active loading spinner during async Drift/DB operations, and provides clear accessibility semantic labels.

3. Discard Dialogs & PopScope

Prevents accidental loss of active bills and unsaved product forms via PopScope interceptors and bilingual showDiscardConfirmationDialog().

4. Pure Validation Suite

12 deterministic pure validators in lib/core/validation/validators.dart for GSTIN, HSN, Barcode, Phone, PIN, Staff PIN, Decimal Prices, Packed/Loose Qty, and Discounts.
